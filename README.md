# WebGL 企鹅实验（精简版 + 三维扩展版）

## 打开方式

解压整个文件夹，使用 Edge 或 Chrome 打开根目录的 `index.html`，选择对应实验。
不需要安装依赖、启动服务器或联网。请保留目录结构，不能只复制一个 HTML 文件。

- `experiment1/index.html`：图片要求对应的二维精简版。
- `experiment2/index.html`：在同一造型和代码基础上完成的三维扩展版。

先点击画布，再按键盘。点击页面菜单或按钮后也会自动回到画布。

## 相比原项目的简化

保留企鹅主题，造型改为身体、头、翅膀、脚、脸、眼睛和嘴，共 12 个简单部件。
去掉帽子、围巾、徽章、换色、换表情、舞蹈、挥翅、一键拆解、自动吸附、缩放与部件检查器。
菜单只保留实验所需的交互选择；每个实验只有一个交互脚本，共用数学、造型和 WebGL 绘制代码。
部件拖动只改变相对身体的位置；随后移动整体时，部件仍跟随企鹅。按“重置”全部归位。
这使代码更容易阅读，也避免了独立世界坐标拆装状态。

## 实验二：PDF 要求对照

| 要求 | 实现与操作 |
| --- | --- |
| 动物拓展为三维物体 | 相同 12 个部件改用球体三角网格，经非均匀缩放构成椭球；启用深度测试及简单漫反射光照 |
| A：沿头部方向前进、后退 | 本地 +Z 为正面/嘴朝向；W 沿旋转后的 +Z 前进，S 反向后退；位置 XYZ 都会改变 |
| A：转向、俯仰、翻滚 | A / D 绕本地 Y 转向；I / K 绕本地 X 俯仰；J / L 绕本地 Z 翻滚 |
| B：以屏幕为参考上下左右移动 | 方向键 ↑ ↓ ← → 沿固定屏幕 Y、X 平移，与企鹅朝向无关 |
| B：绕屏幕坐标轴旋转 | 菜单选择屏幕 X、Y、Z，U / O 进行正向/反向旋转；绕企鹅中心旋转 |

三维版屏幕坐标采用 X 向右、Y 向上、Z 朝向观察者。正交相机固定不动，因此观察坐标轴与屏幕坐标轴一致。
初始企鹅稍微侧转，以便看到三维厚度。状态栏显示位置与当前头部朝向，便于检查前进方向。
屏幕旋转只改变朝向，物体中心位置保持不变，不做绕屏幕原点的公转。

## 核心变换与程序结构

矩阵使用列主序及列向量。`M.mul(A,B)` 表示先执行 B，再执行 A。

单个部件的模型矩阵为：

`Model = T(整体位置 + 跳跃) × R(整体朝向) × T(部件位置 + 拖动偏移) × S(部件尺寸)`

这是平移、旋转、缩放及复合变换的具体应用。

- 物体轴旋转：`R_new = R_old × R_local`（后乘）。
- 屏幕轴旋转：`R_new = R_screen × R_old`（前乘）。
- 物体前进：`position += R × (0, 0, speed × dt)`，按方向向量计算，不叠加平移。
- 跟踪球：将鼠标起止点投影到单位半球。设球面向量为 a、b，旋转轴为 `a × b`，旋转角为 `atan2(|a × b|, a·b)`；增量矩阵在屏幕坐标系前乘。
- 球外鼠标点归一化到赤道；重合点不旋转，反向点选取垂直轴旋转 180°。
- 三维部件拾取：正交屏幕射线逆变换到椭球局部空间，解射线与单位球的二次方程，取最近交点。
- 三维部件拖动：屏幕平面的位移乘朝向矩阵的转置，换算到本地坐标。
- 跳跃：速度按重力逐帧下降，落地时将高度和速度置零。

使用深度测试解决部件前后遮挡；用法线逆转置修正非均匀缩放后的光照。

## 演示顺序

1. 打开实验一：观察白底三色企鹅；整体拖动；切换部件模式拖动一只翅膀。
2. 点击重置，按 D、A 和空格演示移动和跳跃。
3. 打开实验二：鼠标拖动观察前面、侧面和背面，展示体积与遮挡。
4. 点击重置，按 A 改变朝向，再按 W；观察位置和方向状态。按 S 后退。
5. 分别按 I、J，展示本地俯仰与翻滚；方向键展示屏幕平移。
6. 在屏幕旋转轴菜单中依次选择 X、Y、Z，按 U / O 展示固定轴旋转。
7. 切换整体、部件平移模式演示保留的鼠标交互，最后重置。

为方便演示，整体位置有可视范围限制（屏幕 X/Y 和深度 Z），持续移动到边界会停止；在中间区域演示坐标变换即可。
没有引入纹理、模型文件、第三方框架或网络资源。
